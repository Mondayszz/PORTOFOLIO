# 1. 🌿 Back to Nature: A Real-time System for Indonesian Medicinal Plant Identification Using Convolutional Neural Network as an Effort to Strengthen Traditional Medicine
This project develops a system to identify Indonesian medicinal plants from images using a Convolutional Neural Network (CNN) algorithm. The system is designed to facilitate the automated recognition of medicinal plants and support the use of technology to enhance knowledge regarding traditional medicine.A Convolutional Neural Network (CNN) is employed for the image classification of medicinal plants. 5-Fold Cross-Validation is used to evaluate the consistency of the model's performance. Validation performance across the five folds ranges from 71.14% to 79.10%, with Fold 4 achieving the highest accuracy at 79.10%. Evaluation is based on accuracy and loss metrics for each fold. The confusion matrix indicates that while some classes are recognized effectively, misclassifications still occur between certain classes. Evaluation results demonstrate that the model is capable of identifying medicinal plants with an average validation accuracy of 75.10% across the five folds. The confusion matrix also reveals specific misclassification patterns, providing insights into areas where the model can be further improved
# 2. ⚡Solar Photovoltaic System Data Analysis & PredictionSolar Photovoltaic System Data Analysis & Prediction
This project focuses on processing and analyzing data from a PVT (Photovoltaic-Thermal) system to understand solar panel voltage patterns and predict the voltage of Panel A and Panel B using a time-series approach. The analysis process encompasses data cleaning, preprocessing, sequence generation, LSTM modeling, model evaluation, and result interpretation. Cleaning and preprocessing data from multiple PVT system observation periods. Transforming time data and measurement variables into a data structure ready for analysis. Constructing time-series data using the preceding six hours of observations as model input. Building an LSTM model to predict the voltage of Panel A and Panel B. Evaluating prediction results using MAE, RMSE, and R². Analyzing predictions to identify optimal operating hours based on project classification criteria. Determining that the optimal operating hours for both panels fall within the 07:00–16:00 timeframe.Establishing a data analysis workflow—from raw data to predictive model evaluation—and gaining insights into voltage patterns and optimal panel operating hours. This project demonstrates proficiency in data processing, time-series analysis, model evaluation, and result interpretation to generate meaningful information.
